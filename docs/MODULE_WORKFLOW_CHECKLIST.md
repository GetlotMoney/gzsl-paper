# 研究与实验最短检查清单

详细字段见 [实验规范](EXPERIMENT_PROTOCOL.md)，当前目标见 [项目入口](../README.md)。本清单不单独保存成绩或增加审核层。

## 开始前

- [ ] 主线、唯一问题、Idea 和预先判定条件明确；复用相同假设不机械分配新 Idea。
- [ ] 已区分增量、替换或独立新框架；base_commit 由 owner 确认。
- [ ] reuse_scope、change_scope、comparison_ref 明确；代码起点不冒充比较基线。
- [ ] 新尝试已登记正确主线队列；历史编号和账本不改写。

## 运行前

- [ ] pre-run 代码 commit、完整配置、seed、数据/资产、评估与输出位置齐全。
- [ ] 仅做能直接证明改动的最小检查；代码语义变更按 AGENTS 第6节双 Agent 审查，纯记录整理不触发。
- [ ] 需要时已有准确框架图；数据边界与 test 选择披露明确。
- [ ] 实际启动身份与审查一致；新候选未沿失败代码堆叠。

## 结束后

- [ ] 回填原 TRY/RUN，保留失败、中断及无效输出；post-run 仍绑定实际 code_commit。
- [ ] Idea 解释支持/否定什么和适用边界，历史不覆盖；工作状态、证据状态、接纳状态分开。
- [ ] 总索引只更新位置；首页只更新当前决定与下一步。
- [ ] 新正式框架仍须 owner 明确接纳；不自动移动标签、push、发布或清理数据。
