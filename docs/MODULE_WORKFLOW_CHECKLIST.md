# 实验最短检查

操作细节只维护在 [实验规范](EXPERIMENT_PROTOCOL.md)；本页只是导航，不增加表格或审核层。

- **开工**：问题、父代码及授权范围、比较条件、初始化来源、修改范围明确；管理规范取已核实 main。
- **写代码**：保存当前工作，从指定父 commit 创建实验分支；方法目录稳定，不复制整个框架。
- **运行**：同一 Experiment 的 RUNS.csv 一次执行一行；code_commit、完整配置、资产与必要审查一致。
- **结束**：回填原运行记录与 Idea解释；更新 current_record_ref 和下一步，明确 local_only 或远端保存状态。
- **接纳**：owner决定、集成验证、按框架名冻结标签；不强制搬代码，不移动旧标签。

旧实验继续保留原记录格式和身份，新实验不再建立重复 TRY 队列。
