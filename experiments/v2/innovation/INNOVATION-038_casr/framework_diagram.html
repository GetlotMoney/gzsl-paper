CASR：保守自适应句子路由

Base commit：bb5a6a8b5318a29c9fbef445859f6be391d6dc8f；RUN code commit：正式运行后回填。

模型

模型与AOSR相同：固定OESR beta，训练8个softmax句子权重，类名正交化后形成残差原型。

保守loss

loss = CE(seen_logits, label) + 0.1 × KL(sentence_weights || uniform)

KL只防止句子被直接删除，不要求保持等权。使用OESR seed7父权重与随机链。

边界

7,057张seen图像、28,228次更新，每141次official test选全局best。unseen图像不进入梯度；test_used_for_selection=true。
