父路径与固定分支

冻结TG-VPR/TST/CCGR → NCRA → SDRS → SEBC。加载SHA绑定的CCPE top2权重，固定absolute beta=9.177013。

新增共识差距

v1,v2 = top2_n cos(patch_n, local_text_c)
absolute = (v1+v2)/2
gap = v1-v2
final_logits = SEBC_logits + fixed_beta × absolute + beta_gap × gap
beta_gap = 5 × tanh(raw_gap)

若孤立top1是噪声，预期beta_gap为负；若单一强部位更可信，则允许学到正值。raw_gap零初始化，关闭时严格复现CCPE。
