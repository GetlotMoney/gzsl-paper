Base commit：90a84babdf8b1e782e99165dced3ecf4d2de7279；RUN-001 code commit：a19264e0f27c9c2f194b29ee04834e8a9c6e0cac（failed_runtime，未训练）。

输入

父路径：冻结CLS[Ｂ,768] → TG-VPR/TST/CCGR → NCRA → SDRS → SEBC → 父logits[B,200]。新增路径读取冻结patch[B,576,768]以及八角色文本[200,8,768]，不训练CLIP。

新增数据流与公式

patch_score = mean_abs(patch - mean(all_patches))
local_image = Norm(mean(top64(patch_score)))
local_text = Norm(mean(first_6_role_sentences))
text_residual = Norm(local_text - proj_class_name(local_text))
final_logits = SEBC_logits + beta × local_image @ text_residual.T
beta = 10 × tanh(raw_beta)

raw_beta零初始化，关闭时逐值复现SEBC父模型。固定pooling预先计算为[N,768]，训练期间唯一可训练参数是raw_beta。
