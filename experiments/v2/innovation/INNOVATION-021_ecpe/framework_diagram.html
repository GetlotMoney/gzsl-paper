ECPE：episode训练的类别条件patch证据

Base commit：476c92576ed3d69f30469fe06e0974ad1286d6aa；RUN code commit：正式运行后回填。

推理公式

与CCPE完全相同：SEBC logits + beta × 每类top2局部patch平均相似度。关闭beta时严格复现SEBC。

分阶段episode训练

3 folds × (100 pseudo-seen classes + 50 pseudo-unseen classes)
batch = 25 pseudo-seen images + 25 pseudo-unseen images
fold_logits = frozen fold TG + frozen NCRA/SDRS + frozen SEBC
loss = CE(fold_logits + beta × top2_patch_score, 150 global seen classes)

三个fold父模型各自只训练过100类；beta训练使用的所有图像仍属于全局seen 150类。主模型、fold模型和SEBC全部冻结，只训练一个beta。

评估边界

20个episode epoch，每epoch评估official test并保存整次RUN一个最高H。真实unseen图像不进入梯度；U/S/H为200类联合竞争，ZS为50类竞争；test_used_for_selection=true。分阶段优化不同于陈代码单阶段更新，但数据边界和test-selected评估口径一致。
