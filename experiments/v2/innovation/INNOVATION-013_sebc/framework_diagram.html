Base commit：3831d795a75efaedc5cade4830ffa0e2862c0eb0；RUN-001 code commit：6869be8f5b141928b3e4ef29bf4b21da14535d80。

冻结输入与fold数据流

主推理路径固定为TG-VPR/TST/CCGR → NCRA → SDRS，输出[B,200] logits。训练路径复用三个SHA绑定的fold TG模型：每折只用100类训练模型，另50个全局seen类作为pseudo-unseen；三折互斥并覆盖150类。

唯一可训练计算

fold_logits = fold_TG_logits + fixed_SDRS_class_name_residual
corrected_logits = fold_logits - gamma × pseudo_seen_mask
gamma = 2 × tanh(raw_gamma)

raw_gamma零初始化，关闭时逐值返回SDRS父logits。每个episode批次含25张pseudo-seen和25张pseudo-unseen图像，只训练raw_gamma。

loss、推理与评估边界

loss为150个全局seen类联合CE。推理时从真实150个seen类logits减去训练得到的gamma，50个unseen类logits不变。真实unseen图像不进入梯度；U/S/H在200类联合竞争，ZS在50个unseen类竞争。每个episode epoch评估official test，整次RUN只保存一个最高H权重；test_used_for_selection=true，不是blind-test。该分阶段训练不同于陈代码的单阶段优化，但数据与test-selected评估边界一致。
