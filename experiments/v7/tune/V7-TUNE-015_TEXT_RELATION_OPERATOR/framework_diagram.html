TEXT GRAPH
八角色文本边

用每类八个角色句向量形成Mean8 Top3无向边，并固定方向。

D_ab = norm(mean_r(s_a-r)-mean_r(s_b-r))
OPERATOR A
共享低秩视觉化

只用trainval seen中心差分监督seen-seen边；unseen图像不参与梯度。

D_vis = norm(D_text + (D_text W_down^T) W_up^T)
W_up=0 => D_vis=D_text
RIDGE COMPILE
类别关系原型

同一个A作用于全部边，经固定ridge图编译成200类关系残差。

G = solve(B^T B + lambda I, B^T) D_vis / tau
loss = 1 - cos(D_vis, mu_a-mu_b)
DEPLOYMENT
单矩阵出口

推理没有Reader、没有在线图求解、没有逐图关系读取。

Q = Q_TG+S + alpha G
logits = norm(x) Q^T + b
评估边界：训练分类CE只在trainval seen logits上计算；official test仍按200类GZSL竞争与50类ZS竞争记录U/S/H/ZS，并按Full H保存best。
